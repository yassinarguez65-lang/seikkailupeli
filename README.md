# Seikkailupeli

Seikkailupeli on JavaScriptillä ja HTML Canvasilla toteutettu peli.

## Ominaisuudet

- 10 × 10 -ruudukkoon perustuva pelialue
- Pelihahmon liikkuminen
- Pelin tapahtumien näyttäminen
- Inventaarion näyttäminen

## Toteutus

Projekti on toteutettu HTML:llä, CSS:llä ja JavaScriptillä. Canvas-elementtejä käytetään pelialueen, tapahtumien ja inventaarion näyttämiseen.

Projekti on toteutettu osana tieto- ja viestintätekniikan opintoja.
